# Wispr Transcription — Claude Notes

## What This Is
Local voice dictation daemon for WSL2. Hold a hotkey → records mic → Whisper transcribes → pastes text into focused window. No cloud, no subscription.

## Architecture

```
[WSL2 Python daemon]  ←TCP→  [Windows keyhook.exe]
        ↓                           ↓
  sounddevice mic            WH_KEYBOARD_LL hook
  Whisper transcription      sends KEY_DOWN/KEY_UP
  clip.exe → clipboard
  powershell SendKeys → Ctrl+V paste
```

### Key files
| File | Purpose |
|------|---------|
| `wispr.py` | Main daemon — audio, transcription, orchestration |
| `transcriber.py` | Whisper wrapper |
| `indicator.py` | Tkinter recording overlay |
| `config.py` | Hotkey, model, audio settings |
| `keyhook.cs` | C# Windows keyboard hook (source) |
| `keyhook.exe` | Compiled hook (generated by install.sh) |
| `start.sh` / `stop.sh` | Daemon lifecycle |
| `smoke_test.sh` | Post-install verification |

## How to Compile keyhook.exe
```bash
WIN_CS=$(wslpath -w keyhook.cs)
WIN_EXE=$(wslpath -w keyhook.exe)
powershell.exe -NoProfile -Command \
  "& 'C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe' /nologo /target:exe /reference:System.Windows.Forms.dll '/out:$WIN_EXE' '$WIN_CS'"
```

## How to Run
```bash
./install.sh        # first time only
./smoke_test.sh     # verify everything works
./start.sh          # start daemon (logs to ~/.local/share/wispr-transcription/wispr.log)
./stop.sh           # stop daemon
```

## Keyboard Hook Architecture
The Python daemon:
1. Starts a TCP server on a random port (bound to `0.0.0.0`)
2. Copies `keyhook.exe` to Windows `%TEMP%` (avoids UNC path trust issues)
3. Launches it via `schtasks.exe /Create` + `/Run`
4. keyhook.exe connects back over TCP, sends `HOOK_READY`, then `KEY_DOWN`/`KEY_UP`
5. Daemon starts/stops recording in response

keyhook.exe writes a debug log to `%TEMP%\wispr_keyhook.log` on the Windows side.

## Known Issues / Gotchas
- **schtasks Session 0 problem**: Tasks launched via `schtasks.exe /Run` from WSL2 run in Session 0 (non-interactive). `WH_KEYBOARD_LL` hooks installed in Session 0 do NOT receive events from the interactive user desktop. This is the primary unsolved problem as of last session.
- **TCP localhost in WSL2**: WSL2 in NAT mode — `127.0.0.1` from Windows reaches Windows, not WSL2. Requires either mirrored networking mode (Windows 11 22H2+) or using the WSL2 VM's IP. The code currently binds to `0.0.0.0` and keyhook.exe connects to `127.0.0.1` — only works with mirrored networking.
- **PulseAudio**: Must set `PULSE_SERVER=unix:/mnt/wslg/PulseServer` for WSLg audio.
- **DISPLAY**: Must be set for indicator overlay and notify-send.

## Working Principles

- **Simplicity first**: Make every change as simple as possible. Touch minimal code.
- **No laziness**: Find root causes. No temporary fixes or workarounds.
- **Minimal impact**: Only change what's necessary. Avoid collateral damage.
- **Plan before building**: Use plan mode for any non-trivial task (3+ steps or architectural decisions). If something goes sideways, stop and re-plan — don't keep pushing.
- **Prove it works**: Never call a task done without verifying via logs, tests, or direct demonstration.
- **Demand elegance**: For non-trivial changes, ask "is there a more elegant way?" — but skip this for simple obvious fixes.
- **Fix bugs autonomously**: When given a bug report or failing test, just fix it. Point at logs/errors and resolve them without asking for hand-holding.
- **Run `/simplify` after non-trivial changes**: Review changed code for reuse, quality, and efficiency before calling it done.
- **Capture lessons**: After any correction, update `MEMORY.md` with the pattern to avoid repeating it.
- **Scope challenge before building**: Ask "what already exists that solves this?" and "what's the minimum change to achieve the goal?" before writing code.
- **Failure modes**: For each new codepath, identify one realistic way it fails in production (timeout, race condition, silent error, etc.) and confirm it's either tested or handled.
- **Defer explicitly**: When skipping something intentionally, note it and why — in a comment, in the plan, or in `MEMORY.md`. Undocumented deferrals become forgotten debt.
- **ASCII diagrams**: Use them for non-trivial data flow, state machines, and processing pipelines — in plans and in code comments where behavior isn't obvious.

## Config
Edit `config.py` to change:
- `HOTKEY` — default is `"Alt_R"` (Right Alt)
- `WHISPER_MODEL` — default `"medium"` (~1.5 GB); `"small"` is faster
- `WHISPER_LANGUAGE` — default `"en"`
